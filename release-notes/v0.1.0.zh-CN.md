## Project Report Workbench v0.1.0

[English](v0.1.0.md) | 简体中文

仓库首次发布：可复用、证据可追溯的周期报告工作流。

### 包含内容

- 项目初始化、配置验证、流水线执行、检查点与依赖感知缓存。
- CSV/XLSX 数据探查与周期指标分析。
- 项目版本管理、反馈、有界调优及经验学习流程。
- 英国电力与合成零售示范项目。
- 精简英文 README 和中文指南链接。

### 开始使用

需要 Python 3.10+。安装 `config/requirements.txt` 中的依赖，然后按 `readme.md` 和 `SKILL.md` 操作。

### 验证与范围

- 发布准备前，77 项通用测试通过。
- 输入数据集与运行产物不包含在仓库中，需要单独准备。
- 复杂分析和报告格式需要项目适配器，并进行数值、证据和视觉验证。
- 此标签对应工作台仓库版本；示范项目各自保留独立版本号。
