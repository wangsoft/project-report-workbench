## Project Report Workbench v0.1.0

First repository release: reusable workflows for evidence-backed periodic reports.

### Included
- Project initialization, configuration validation, pipeline execution, checkpoints, and dependency-aware caching.
- CSV/XLSX profiling and periodic metric analysis.
- Project versioning, feedback, bounded tuning, and experience-learning workflows.
- UK electricity and synthetic retail example projects.
- Concise English README with a linked Chinese guide.

### Getting started
Requires Python 3.10+. Install dependencies from `config/requirements.txt`, then follow `readme.md` and `SKILL.md`.

### Validation and scope
- 77 shared tests passed before release preparation.
- Input datasets and generated workspace outputs are excluded from the repository and must be prepared separately.
- Complex analysis and report formats require project-specific adapters and numerical, evidence, and visual validation.
- This tag versions the workbench repository; individual example projects retain their own versions.
