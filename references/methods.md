# 方法选择：以决策问题为入口

[English](methods.en.md) | 简体中文

这是一组候选分析路径，不是包罗所有领域的权威方法库。与行业相关的标准、会计口径或监管定义应从用户资料及适用的官方原文另行核实；不以来源声望代替适用性。

## 选择表

| 要回答的问题 | 首选分析 | 数据要求/限制 |
|---|---|---|
| 发生了什么变化 | 总量、同比/环比、预算差异、绝对增减 | 可比期间、同一口径；缺上年同期不能编造同比 |
| 变化集中在哪里 | 可加指标按维度分解增减额和贡献 | 类别互斥且完整、包括未知组；贡献不等于因果 |
| 比率为何变化 | 分子分母分别变化、权重与结构分析 | 汇总比率重算分子/分母，不能平均各组比率 |
| 是否异常 | 分布、历史基线、季节性、已知事件检查 | 阈值来自业务容忍度或验证；异常不是自动删除依据 |
| 客户是否留存 | 固定 cohort、观察窗口、流失定义 | 完整用户/交易历史，处理右删失与窗口不一致 |
| 措施是否有效 | 先检查实验/对照与识别条件 | 前后变化和相关性不足以证明因果；缺条件只描述关联 |
| 未来可能怎样 | 朴素/季节性基线再与候选预测比较 | 足够历史、滚动时间验证、区间与误差；不凭两期拟合长期趋势 |

NIST 的 [EDA 介绍](https://www.itl.nist.gov/div898/handbook/eda/section1/eda11.htm) 支持先探索结构、异常和假设的做法；[时间序列介绍](https://www.itl.nist.gov/div898/handbook/pmc/section4/pmc4.htm) 提醒考虑趋势、季节性与自相关。这两页不能作为上表所有业务方法的统一背书。检查日期：2026-10-31。

## 计算约定

- 增长率默认 `(current - previous) / previous`；基数为零或负数时不自动给通常意义的增长率，报告绝对变化并按业务口径解释。
- 比率变化区分百分比与百分点；10% 到 12% 为 +2 个百分点、相对 +20%。
- 类别贡献为 `delta_i / delta_total`，仅用于可加指标与一致类别空间。正负抵消时贡献可能超过 100%；净变化接近零时隐藏不稳定的贡献比例，保留各项绝对变化，近零阈值由业务精度确定。
- 部分期间与完整期间不可直接比较。使用同期同进度、日均等办法时说明假设及营业日差异；日均不能自动消除节假日/季节性。
- 缺失类别不默认补零：先判断“确实无交易”还是“未采集”。对分类变化做映射或明确不可比。

## 方法卡

每条进入项目 的方法记录：`method_id`、决策问题、权威/原始来源或“内部约定”、核实日期、输入要求、算法、假设、适用范围、失效条件、证据要求、对应测试。

历史经验升级为规则前，寻找跨期重复证据和反例。只有当期支持的经验写为假设或条件规则。方法论新增的分析只有在数据支持且影响决策时进入正文，其余放附录或省略。
