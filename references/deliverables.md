# 单一 skill、多个项目与独立运行记录

不生成新的 `SKILL.md`。本 skill 保留通用方法和执行入口，项目保存业务差异，运行目录保存当期事实。

```text
project-report-workbench/
  SKILL.md
  scripts/                     # 通用管理、探查、计算与计时工具
  references/                  # 通用规程
  projects/<project-id>/
    project.yaml               # 项目身份、版本、输入、资源与阶段配置
    references/
      data-contract.md
      analysis-rules.md
      report-spec.md
      visual-spec.md           # 需要视觉报告时
      sop.md
    scripts/                   # 实际业务计算、校验、渲染代码
    templates/                 # 已清理的模板与授权品牌素材
    tests/                     # 固定预期值的业务回归
    evals/                     # 版本评价与验证范围
  workspace/<project-id>/<run-id>/
    run_state.json             # 原始参数、配置快照、指纹、阶段状态与耗时
    logs/
    ...                        # 配置声明的指标、证据、叙事、报告和验收产物
```

按实际需要创建文件，不为凑目录生成空脚本。`init` 只创建候选配置；没有业务样本时不声称流水线已经可用。配置格式及运行命令见 [项目配置与积累](project-workflow.md)。

项目契约固定指标语义、版本、关联粒度和来源；分析规则固定方法、触发条件、例外、假设重验与冲突处理。SOP 用“输入、动作、输出、检查、失败处理”描述流程，引用同一规则 ID，不复制第二套算法。叙事组件引用结论和指标 ID；实际问题覆盖表、差异核对、假设证据与失效影响清单保存在运行目录。

需要 PDF/PPTX 时，按 [视觉逆向规程](visual-reverse-engineering.md) 保存视觉规范、模板来源、颜色语义、字体、页面容量和溢出处理。清除旧期结论、备注、图表缓存与嵌入数据；无来源时明确标为新设计候选。品牌资产只用于对应授权项目，不混入通用资产。

计算、清洗、制图、回填和检查优先使用脚本；本 skill 负责选择配置、执行阶段、必要模型综合及例外。见 [执行与性能规程](execution-performance.md)。提供真实调用示例、依赖说明和实际测试结果，未测性能或视觉效果明确标注。项目的 `validated` 标签不能替代带版本和样本范围的验收证据。

原始数据、参考报告、逐页提取、当期事实和日志保存在授权的运行或外部数据目录，不作为可分发的通用技能内容。项目配置与模板也可能包含客户信息；分享本 skill 时仅包含通用文件和合成测试，按授权单独导出项目。保存在本地不等于自动安装或发布。
