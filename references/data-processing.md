# 数据处理规程

## 先探查，再决定成本

原始文件保持只读；记录 SHA-256、文件大小、来源版本和报告截止日。先检查 Sheet 清单、隐藏状态、维度提示和少量带行号的样本，识别标题区、多层表头、合并区、多个表块与小计。Excel 的 `max_row/max_column` 是范围提示，不是有效业务记录数。

`profile_table.py` 默认每表检查前 200 个物理行、前 128 列，只保存前 5 行短样本；可调整 `--scan-rows`、`--max-columns`、`--sample-rows`。`--full-scan` 扫描所有物理行，但仍受列宽上限约束；全空行与业务记录不是同一概念。计数含表头，不自动减一。`--sample-rows 0` 禁止保存样本值。隐藏行、合并范围、外部链接、数据透视缓存和嵌入对象需要额外检查，脚本不会宣称已覆盖。

不强制全表计数后再读一遍。若真正需要全量质量检查，将计数、类型检查、合计和转换合并为一次流式过程。只探查前部会漏掉后部类型变化，因此生产校验仍需覆盖全部使用的数据。

选择策略依据目标列宽、文本长度、估计内存、重复读取次数和运行环境，而不只看行数：

- 小表且内存充足：读取必要 Sheet/列/范围，保留原始值副本。
- 重复分析或较大表：规范化后生成有 schema 的 Parquet；只读取需要的列、分区和时间范围。
- 内存不确定：openpyxl `read_only`/CSV 分块读取 → 显式 schema 转换 → 分块落盘或聚合；不在最后把所有块再拼回内存。
- Arrow/DuckDB 不可用时，小表可用已有库，大表用标准库流式聚合或明确依赖缺口，不强依赖其他 skill。

openpyxl 的共享字符串等元数据仍可能占用内存；“只读”不是无条件恒定内存保证。估计需为解析、连接和中间结果留余量，观察峰值后调整块大小。

## 类型与清洗

| 情况 | 处理规则 |
|---|---|
| 多层/合并表头 | 记录原位置和展开映射；只在已识别的表头/分组范围填充，禁止整表 ffill |
| 重复或清洗后重名字段 | 使用带原列号的稳定内部键；不能用字典覆盖同名列 |
| 编号、邮编、前导零 | 保持字符串；数值单元格显示格式可能补零，需结合格式与业务字典 |
| 金额与比例 | 明确币种、元/万元、含税口径、精度；12% 转 0.12，0.12 与 12 不能凭值大小猜单位 |
| 数字文本 | 按约定 locale 处理千分位、小数点、括号负数；保留原值、解析结果和失败原因 |
| 缺失 | 区分未知、不适用、未发生、零；空字符串及 NA 标记按字段定义处理 |
| 异常值 | 标记并调查，不能仅因 IQR 超界自动删除真实业务事件 |
| 去重 | 以业务键、版本和粒度决定；相同行可能是两笔交易，保留删除依据和金额影响 |
| 字符标准化 | 仅执行明确的空格/大小写/别名转换；不要删掉全部非中文或所有非数字字符 |
| 精度 | 金额用约定的 Decimal 或最小货币单位整数；禁止默认降成 float32 |

日期显式处理 Excel 日期系统、时区、财务周/月、未完整期间、事件发生日与入账日。Excel 日期样式和序列值不能脱离工作簿上下文解释。

每次转换记录输入行数、输出行数、隔离行数、影响金额、规则版本。解析失败写入隔离表；禁止 `errors='coerce'` 后不报告丢失量。全缺失组求和不能自动成为真实零。

## 公式与多表关联

`data_only=True` 只读已有缓存，不计算公式。检查公式视图与缓存视图；缺缓存、错误值和外部依赖要标记。缓存非空也可能陈旧，需确认重算时间/来源或独立重算关键指标。不能把无缓存公式当空数据丢掉。使用表格软件重算时在副本操作，并记录软件版本；不能把 openpyxl 保存当成重算。

明细、汇总、目标、维表分开识别；禁止把汇总行混入明细再次求和。跨 Sheet/文件 join 前约定键和基数；检查空键、重复键、未匹配率、连接前后行数及金额。意外多对多或扇出导致关键指标变化时停止相关计算，修复粒度后重算。

## 缓存与导出

缓存 key 包含来源内容哈希、Sheet/范围、字段映射、转换版本、数据契约和 schema。文件存在不代表有效。用临时文件写入，完成行数/合计核对后原子替换，失败时不留下可复用的半成品。不同来源不能共享固定 `/tmp/_auto_parquet.parquet`。

显式定义分块 schema，处理全空首块和后续类型变化；不能为了避免 schema 报错将规范数据层所有字段转成字符串。可以保留字符串原始暂存层，但分析层须经契约化转换并保留行定位。

优先向量化与聚合；无法向量化的有限业务逻辑可分块迭代，不作无条件禁令。大输出用 write-only 或分区文件；Excel 每表最多 1,048,576 行，包含表头。输出文本到表格时将不可信的公式形文本按文本写入，保留真正需要的公式并显式检查。

图表读取已验证的指标表，标题标期间与单位；中文字体用环境实际可用字体并渲染确认，不照抄某台服务器的绝对字体路径。下载/文件链接使用当前宿主支持的路径格式。
