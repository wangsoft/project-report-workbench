# 视觉逆向与模板生成

目标是提炼可跨期复用的设计系统，并让内容变化后仍能清楚表达。分别评价分析质量和视觉质量；相似的外观不证明数字正确，准确的数字也不证明页面可读。

## 1. 建立视觉证据

记录来源文件哈希、页码/幻灯片 ID、页面尺寸与方向、渲染器及版本、渲染尺寸。先看全篇缩略图了解重复模式，再放大每种页面类型及特殊页；不要从封面推断整个报告的风格。代表页抽样仅用于发现模式，最终输出逐页验收。

### PPTX

- 检查主题颜色与字体、母版、布局、占位符及幻灯片局部覆盖。颜色可能是主题引用叠加透明度/明暗变换，字体也可能从上层继承；缺显式值不等于没有样式。
- 检查文本框的段落/文字样式、边距、行距、对齐、自动缩放；记录形状位置、尺寸、层叠、分组变换、裁剪与背景。
- 区分原生图表/表格、嵌入对象和截图。截图无法直接恢复可编辑数据；装饰图也不能当作分析图表。
- 从结构读取的值与渲染外观交叉核对。记录主题字体是否在当前环境可用；替代字体可能改变中文换行、字重和行高。
- PPTX 缺少渲染工具时，可完成结构提取并标为“视觉待核对”，不能宣称继承关系或字体呈现已验证。

### PDF

- 检查每页页面框、旋转、可用文本/字形、矢量和栅格对象。区分文本型、扫描型与混合页面；存在文本层不代表整页文字都可直接提取。
- 对扫描/图像区域 OCR，并在图上核对读数。字体、字号、颜色和边界无法可靠提取时记录估计值及置信度；不要从截图承诺恢复原主题、母版或可编辑对象。
- 转换坐标时记录原点、旋转和单位；跨页面用归一化矩形 `[x/W, y/H, width/W, height/H]` 比较布局，同时保留原始坐标。
- 配色采样避开反锯齿边缘与压缩噪点，结合重复出现的位置判断角色；照片里出现最多的颜色不一定是品牌色。
- 只有 PDF 时，可按观察重建可编辑模板，但明确这是重建版本；需要再次渲染核对，不称为原生模板提取。

## 2. 提炼视觉规范

每个视觉 token 或规则记录：`id`、`role`、`value`、`unit`、`source_file_hash`、`source_pages`、`evidence_kind`（对象提取/渲染观察/估计/新设计）、`confidence`、适用页面及覆盖规则。数值示例或估计值不能冒充来源实测值。

| 类别 | 必须提炼的内容 | 判断要点 |
|---|---|---|
| 页面 | 比例、方向、边距、网格、页眉页脚、页码与 Logo 区 | 多种尺寸分开记录，不强行统一 |
| 配色 | 背景、正文、品牌、强调、分隔线、图表系列、风险/正负/目标角色 | 区分分类颜色与好坏含义；下降不一定是坏事 |
| 字体 | 中西文字体、标题/副标题/正文/注释层级、字重、行距 | 使用有效字体和实际显示值；缺字体记录替代与差异 |
| 布局 | 对齐关系、列宽、间距、留白、标题及结论区位置 | 记录约束与可伸缩区域，而不只是固定坐标 |
| 图表 | 类型、轴范围与单位、刻度、基准线、图例、标签、线宽、数据来源区 | 新值超出旧轴范围时重算；不得截断负值或新增类别 |
| 表格 | 表头、行高、条纹、边框、数值对齐、单位、汇总强调 | 长表分续页并重复表头，不靠缩小字体塞下 |
| 注释 | 来源、口径、限制、重点标注的层级与位置 | 重要限制不能降成不可读小字 |

输出规范中区分三类决定：保持（稳定品牌/语义）、适配（新内容引起的布局变化）、修正（原报告的可读性或表达缺陷）。记录理由；用户要求严格复现时保留其意图，存在无法兼得的限制就如实说明。

分类系列颜色以稳定实体 ID 绑定，不以排序位置绑定；新增类别分配未占用的可区分样式。增长/下降、优/劣、风险与品牌色是不同语义；根据指标方向解释，标签/符号提供冗余信息，不能只靠红绿辨识。

## 3. 从页面归纳模板

仅生成证据支持且业务需要的类型，例如封面、执行摘要、KPI 概览、趋势、分组对比、贡献分解、建议、附录。相同版式在不同报告中作用不同，按“回答的问题＋内容结构”命名，不只按页码命名。

每个模板包含：

- `template_id`、用途、来源页面、视觉规范版本。
- 内容槽位及绑定：标题、结论、指标、图表、来源脚注；记录必填与可选。
- 几何与层级：画布、区域、锚点、对齐和间距；装饰不覆盖内容。
- 容量：可容纳的文字长度、系列/类别数、表格行数；上限由渲染试验确认，未测试则标为候选。
- 自适应顺序：压缩重复表述 → 调整留白/区域 → 切换布局或图形 → 拆页。不得为了套模板删除关键证据，也不无限缩小字号。
- 可编辑性：哪些对象是原生图表/表格/文本，哪些只能使用图片及原因；PPTX 默认优先可编辑对象，不能将整页截图作为唯一“模板”。
- 图表数据来自已验证指标表；系列颜色和数值格式引用统一规范，不能在每页另写一套。

提供可使用的模板文件或实际生成代码，二者按环境选择；仅有规则文档时称为视觉规范，不称为已生成可用模板。

## 4. 清理与跨期适配

从原 PPTX 复制布局时清理旧文本、备注、隐藏页、旧图表缓存、嵌入工作簿、评论及不再需要的外链；保留确实需要且可使用的品牌素材。客户专用素材只进入该客户授权的项目，不加入通用本 skill。检查发布包内容，不仅检查可见页面。

视觉学习只能使用训练期或预先提供的独立品牌模板，不读取留出报告来挑选布局。训练页中的历史结论、图形走势和图片不能以“视觉模板”名义泄露给留出生成。样式比较所需原页面只供评测阶段使用。

新一期可能有更长标题、更多类别、缺失指标、负值、新数量级和多页表格：先选择能表达本期发现的页面类型，再应用视觉规范。缺失指标不能保留旧期卡片值；续页保持口径、标题关联与来源。

## 5. 双层验收

**结构检查**：槽位已替换；指标表与图文数字一致；画布尺寸、系列映射、字体配置符合规范；元素越界和意外重叠已检查；发布包不含旧期隐藏数据。几何检查不等于文字实际没有溢出。

**渲染检查**：逐页检查最终文件，缩略图看一致性，原尺寸放大看中文、数字、图例、脚注、对齐、留白和截断。PPTX 最终交付若另有 PDF 导出，也检查导出的 PDF；不同渲染器可能造成差异，应记录实际目标。

与源页面/模板比较时分别评价品牌一致性、层级、布局规律、颜色语义、可读性和内容适配。新一期内容变化不能靠整页像素相似度判优劣；叠图/像素差仅辅助检测预期固定区域的漂移。

至少实际试排一种正常内容与一种容量压力场景（长中文标题、多类别或长表，按本报告实际风险选择）。未拿到真实参考报告时这些检查为待执行，不能以规程完整替代验证。

视觉验收记录每页 `page_id/template_id`、规范版本、结构检查结果、渲染图路径、问题严重度、修订及最终状态。关键遮挡、数字缺失或颜色误导未解决时，视觉不通过；分析结论正确仍可单独交付文本稿并说明视觉部分未完成。
