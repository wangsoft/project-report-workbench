# 英国区域电力示范项目

[English](project-spec.en.md) | 简体中文

## 范围与来源

DESNZ Energy Trends 区域电力专题，2024 年发布版（数据截至 2023）用于规则/视觉学习，2025 年发布版（数据截至 2024）用于跨期重放。原文件与下载 URL、SHA-256 留在 `workspace/public-fixtures/uk-electricity/source-manifest.json`，不打包进通用 skill。官方汇总表不是逐电厂明细。检索时已看到两版摘要，本次不是盲测，不推断泛化能力或超越分析师。

0.2.0 为四页事实模板。0.3.0 针对 2024 数据升级为十五页全主题候选报告，逐页核对官方十二页材料，覆盖发电、消费、贸易、燃料、低碳、可再生技术、外部背景、修订及两项附录。主题覆盖不等于逐句复刻、所有因果解释独立验证或人工业务验收。覆盖契约见 coverage.json。

## 数据与分析规则

- 单位 GWh，展示 TWh；低碳 = 核能 + 可再生能源，其他燃料和储能不归入低碳。
- 以表头“年份＋地区”和指标名称定位，不按固定行号或最新列位置。新版增加 Low Carbon 行仍可识别总量。
- 仅使用明确的 All generating companies 行，不累计分项与小计。必需值缺失、文本、非有限值或无公式缓存时停止。历史电池储能缺失保留为 null；贸易允许带符号净额。
- 同比采用本版 current/previous，不混用历史版基期；旧版与新版同年差额单列为修订。
- 分析窗口最近五年；早期跨表冲突不进入报告，保留在质量产物中。使用期跨表差异 > 0.001 GWh 披露，> 0.01 GWh 阻断。后一门槛是本描述性报告的显示重要性选择（10 MWh，相对于显示单位 0.01 TWh 小 1000 倍），不代表已查明源数据差异原因。地区求和容差 0.05 GWh 依据部分分项仅保留两位小数。
- full_data 读取煤、油、气、可再生技术和供需分项。历史极值只在燃料表同一来源的 2004 年起序列核对，不能将早期跨表冲突当作已解决。
- 2020 年化石燃料分项与合计差异、2024 年供需平衡与公共/自发消费加总差异均保留；计算正确性通过不等于源数据守恒成立。2020 年北爱尔兰负余项为差额，不解释为负储能。
- 外部 context.json 按年份绑定 DUKES 文献与地图 SHA-256。历史政策背景有来源链接。原因解释明确归属外部文献，未建立独立因果模型。换期必须更新背景与覆盖契约，禁止无提示复用旧期解释。

## 视觉学习与适配

参考：2024 发布版 PDF 第 1 页的摘要层级、第 2 页的能源堆叠条形图；白底、A4 纵向、分类蓝色、页脚分隔线。颜色为渲染观察后的近似重建，并非原主题精确提取。化石燃料紫蓝、核能深蓝、可再生浅蓝；新增灰色“其他及储能”补足总量。中文 STSong-Light 替代英文源字体；取消政府署名与 Logo，标注为工作台试运行稿，避免误认官方报告。最终 PDF 每页渲染检查。

新版页面：摘要、区域趋势、消费、贸易台账、燃料与历史、低碳、两页地区燃料、可再生趋势、技术比较、外部背景、源表差异、电站地图、政策历史及覆盖索引。Chart 2 用并列表表示，附录 A 用带残差的流量台账表示；不强行画闭合桑基图。附录 B 引用独立 DUKES 2025 图件并保留授权署名，非由汇总数据生成地图。图表由相同 evidence.json 绑定；页码、单位和证据 ID 可检查。限制固定五地区/五年，不宣称适配任意类别数。段落超容量直接失败，不缩字吞内容。

## SOP 与验收

normalize → compute → check → render → verify。前两阶段稳定计算；check 核对源表、指标公式、单位期间、结论引用、趋势与修订；verify 检查 PDF 关键数值、页数、边界及产物哈希。自动检查和逐页视觉记录分开，人工业务评审保留 pending。

输入 baseline 为旧版规范化 JSON，只包含表格值与定位，不含官方报告结论。规范化 JSON 本身为受控输入并记录哈希；其与原始 workbook 的来源关系需维护者审核，运行器不会自动下载或追溯外部数据。

失败时保留本次日志；修改输入/脚本后创建新运行。复核、改进与发布使用通用 project_versions.py。该项目的规则与数据差异不得直接推广到其他客户。

0.3.0 运行使用 2025-release/full-inputs.json，另需 context、context_source、map 三个输入。原 inputs.json 用于旧归档版本。缓存测量不含外部检索、来源人工整理和视觉复核时间。原报告正文与 Excel 的天然气五年变化等差异保存在独立对照记录，不通过改算式迎合原文。
